数据模型速查

PostgreSQL 是真相源；Qdrant 只索引 active child chunks；检索默认受四重可见性约束。

核心实体关系

documents 1──* document_versions
    │               │
    │               └──* chunks (parent / child)
    │                     parent_chunk_id 自引用
    └── current_version_id → 某一个 version

documents 1──* ingest_tasks
query_logs 1──* feedback
eval_datasets 1──* eval_dataset_items
eval_datasets 1──* eval_runs 1──* eval_run_items

默认检索可见性（必须同时满足）

  1. documents.status = active
  2. document_versions.version_status = active
  3. 版本是该 document 的 current_version_id
  4. chunks.is_active = true 且 chunk_type = child

关键字段

documents

doc_type、status、current_version_id、security_domain、tags

document_versions

version_no、file_hash、version_status、storage_path

chunks

chunk_type、chunk_hash、parent_chunk_id、search_tsv、is_active、页码/条款元数据

ingest_tasks

task_type（ingest/replace/reindex）、status、progress、error_message

非显而易见规则

  • upload 只创建新 document；新版本走 replace。
  • parent 存库但不进 Qdrant / 关键词主索引。
  • chunk diff 主键是 chunk_hash，不是 chunk_index。
  • unchanged child 在新版本仍会落新 DB 行，但可复用旧向量。
  • 任务状态：Redis 实时 + DB 持久；业务查询以 DB 为准。
