RAG_Sec 术语表

统一中文/英文术语。所有课程尽量使用这里的定义，避免混用别名。

核心概念

RAG
Retrieval-Augmented Generation，检索增强生成：先从知识库召回证据，再让大模型基于证据生成答案。
Chunk
文档切片。把长文档切成可检索、可引用的文本片段。
Child Chunk
检索单元。只索引到 Qdrant 与 PostgreSQL FTS；通常约 300–600 tokens。
Parent Chunk
上下文单元。只存 PostgreSQL，不进向量/关键词检索；检索命中 child 后按 parent_chunk_id 回取。
Ingest Task
异步入库任务（ingest_tasks）。状态典型为 queued → processing → completed/failed。
File Hash
原始文件字节的哈希（如 SHA-256）。替换时用于快速判断文件是否 unchanged。
Chunk Hash
基于 normalized_text 的哈希。增量更新时以它判断 child 是 added / removed / unchanged。
Active / Soft Delete
逻辑可见性：document/chunk 标记为 deleted 或 is_active=false，并同步关闭 Qdrant/FTS 可见性，而不是物理删主路径。
Golden Dataset
评测样本集（默认 eval/golden_dataset.jsonl），可物化到 eval_datasets / eval_dataset_items。

流程术语

Hybrid Retrieval
向量检索 + 关键词检索（PostgreSQL FTS，必要时 ILIKE fallback）再经 RRF 融合。
RRF
Reciprocal Rank Fusion，按排名倒数融合多路检索结果；本项目默认 k=60。
Query Rewrite
查询改写：在 intent / term expansion 后生成 rewritten_query、search_keywords、sub_queries。
Safety Guard
查询链路第一步：识别攻击性请求，输出 allow / refuse / redirect。
Citation Checker
检查答案关键结论是否被检索证据支持，并校正引用字段。
Chunk Diff
替换文档时，以 child chunk_hash 对比新旧集合，只对变化部分重新 embedding/索引。
