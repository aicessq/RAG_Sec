四条主流程图

读本项目时，优先用这四条链路建立骨架，而不是按文件名乱翻。

1. 上传 / Ingest

upload API
  → upload_service（校验 / 存盘 / 建 document+version+task）
  → Celery ingest_worker
  → parser → cleaner → chunk
  → 只为 child chunk 做 embedding
  → Qdrant upsert + PostgreSQL FTS
  → ingest_task completed

关键文件：api/upload.py、services/upload_service.py、workers/ingest_worker.py、parser_service、cleaner_service、chunk_service、index_service。

2. 查询 / Answer

query API
  → safety_guard
  → intent_classifier
  → term_expander
  → query_rewriter
  → metadata_filter
  → hybrid retrieval（vector + FTS）
  → RRF → reranker
  → parent context 回取
  → answer_generator
  → citation_checker
  → query_log

关键文件：api/query.py、services/query_service.py 及 safety/intent/rewrite/retriever/answer/citation 系列服务。

3. 替换 / Soft Delete

replace API
  → file_hash 快速比对（unchanged 则拒绝新建版本）
  → 新 version + replace task
  → 重新 parse/clean/chunk
  → 以 child chunk_hash 做 diff
  → added 重嵌索引 / unchanged 复用向量 / removed 三端停用
  → 切换 current_version_id

soft delete：
  documents.status=deleted
  chunks.is_active=false
  Qdrant / FTS 可见性同步关闭

关键文件：api/documents.py、services/update_service.py。

4. 评测 / Eval

eval/golden_dataset.jsonl
  → eval_service 物化 dataset/items
  → 对每条样本跑真实 query 链路
  → Recall@K / MRR / citation accuracy / refusal accuracy / latency
  → 写入 eval_runs / eval_run_items

关键文件：api/eval.py、services/eval_service.py、eval/golden_dataset.jsonl。

读代码口诀：API 找入口 → Service 找流程 → Worker 找异步 → Models 找持久化 → Qdrant/FTS 找检索可见性。
