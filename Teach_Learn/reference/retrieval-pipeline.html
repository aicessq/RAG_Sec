检索管线参数速查

第一版默认参数来自规格决策表；改代码前先确认是否故意偏离这些值。

默认参数

阶段默认值说明
Qdrant metricCosine向量相似度
Vector top_k30向量初筛
Keyword top_k30FTS 初筛
RRF k60融合平滑常数
Rerank 输入融合后前 20真实 reranker 重排
Evidence top_k5最终进答案的证据数
FTS主检索ILIKE 仅作中文召回不足时的 fallback

流水线顺序

rewritten_query
  → vector search (30)
  → keyword search (30, FTS + 可选 ILIKE 并入)
  → RRF fusion (k=60)
  → reranker (top 20 → reorder)
  → evidence top 5
  → parent context reconstruction
  → answer + citation check

过滤默认值

  • is_active=true
  • version_status=active
  • current_version_only=true
  • 用户显式 filter 与系统 filter 冲突时，用户显式优先
调试检索质量时：先用 /api/v1/query/retrieve 看融合结果，再用 /query/rewrite 看改写与 filter，最后才怀疑 answer prompt。
