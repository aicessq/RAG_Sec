项目结构速查图

用途：当你不知道某个功能该看哪里时，先看这张地图。

一眼看懂仓库

backend/

FastAPI 后端、数据库模型、服务层、Celery worker、测试。

frontend/

React + TypeScript + Vite 前端 MVP，调用后端 API。

Doc/

项目规格、阶段说明、面试/学习材料。Doc/文档2.MD 是权威规格。

eval/

评测数据，例如 golden dataset。

models/

本地模型资产或模型相关文件。

docker-compose.yml

PostgreSQL、Redis、Qdrant、backend、worker 等服务编排。

后端内部地图

backend/app/
├─ main.py              # 创建 FastAPI app，注册中间件和 routers
├─ api/                 # 薄路由层：只处理 HTTP 输入/输出和异常翻译
├─ services/            # 核心业务流程：ingest、retrieve、answer、eval、update
├─ models/              # SQLAlchemy ORM 模型
├─ schemas/             # Pydantic 请求/响应结构
├─ db/                  # 数据库连接、session、Base metadata
├─ prompts/             # LLM prompt 模板
└─ workers/             # Celery app 与异步 ingest worker

四条主流程

  1. 上传 / ingest：文件校验 → 存储 → 创建记录 → Celery 解析清洗切块 → 只索引 child chunks。
  2. 查询问答：safety → intent → term expansion → rewrite → metadata filter → hybrid retrieval → answer → citation check。
  3. 替换更新：上传新版本 → chunk hash diff → 只新增/复用/停用变化的 child chunks → 切换 current version。
  4. 评测：读取 golden dataset → 跑真实查询链路 → 计算 Recall/MRR/citation/refusal/latency → 入库。
读代码口诀：先找 API 入口，再跳 service；如果是后台任务，再跳 worker；如果涉及持久化，再看 models 和 migrations。
